# V1.0 功能范围与 G0 审查

阶段 0 · P0-T5 · 2026-11-26

范围以发起人最终逐项选择及此前明确修订为准。首版是 **iPhone 上个人本地音乐的完整获取、组织、播放闭环**。阶段 3 的 Alpha 只贯通主干，阶段 4 补齐已承诺功能，阶段 5 进行正式验收。用户决策的范围、待核验的平台能力、待制定的产品细则分别记在下表。

## 已确认纳入 V1.0

### 核心闭环

| 模块 | 范围和约束 | 落地依赖 |
| --- | --- | --- |
| 本地获取 | 建议使用可在 iOS「文件」中管理的应用媒体文件夹，也允许通过授权访问外部本地文件/目录。明确提醒删除 App 会删除其容器媒体，说明系统「卸载 App」和「删除 App」的区别。外部文件暂不可用时保留索引/组织成果，提供定位或重新授权途径。 | P1-T1/T3 核验覆盖续签、容器与授权；G2 定提醒位置和异常交互。 |
| 资料库 | 专辑为核心，组织偏好依次原生专辑、自设专辑、作者、合集，作者归入分类。完整专辑始终可查看，未听且整张收藏默认展示完整，已听且收藏部分曲目默认展示所选曲目。由发起播放时的视图决定播放范围。 | [产品设计 M3.3/M3.4](../../PRODUCT_DESIGN.md#m33-资料库收录专辑展示与播放联动) 的规则交界归 G2。 |
| 播放 | 有线含现有 USB DAC，涵盖本机扬声器和由系统协商的蓝牙。以原生采样率、有效位深和声道为默认目标，兼容规格无缝，跨规格质量优先。支持顺序、随机、列表循环、单曲循环。从专辑/歌单等上下文播放。默认恢复上次曲目开头，可改为记忆秒数。 | P1-T2 核验会话、音质、格式与可读字段，G2 定其他入口上下文、重开时是否恢复范围与自动起播。 |
| 系统歌单和媒体信息 | 不可删除内置「收藏」入口，内容可编辑；最近 500 首「播放历史」可删，独立于当前播放。读取原生歌词、曲目信息及专辑介绍。 | G2 定历史删除粒度、去重/追加口径及缺失信息的交互。 |
| 界面与系统集成 | 「资料库 / 音乐 / 设置」一级导航，顶部搜索，默认首页为「音乐」且可调整。全局小播放器和完整播放页，支持后台播放、锁屏控制和系统中断恢复。 | G1 验证系统能力，G2 确定视觉、入口呈现、设置分组和播放视图。 |

| 功能 | 已确认范围 | 主要成本、依赖与后续定案 |
| --- | --- | --- |

| 多维分类 | 首次自动识别，可去掉错分/冗余，支持沿用文件夹组织与手动分类，曲目长按可选一个或多个类别（n ≥ 1）。 | 中高。依赖标签解析和稳定 ID，G2 定专辑层归属与多选细节。 |
| 自定义歌单 | 创建和管理歌单，支持歌单内自定义曲目顺序。 | 中。依赖稳定曲目 ID，G2 定操作及推荐交互。 |

| 搜索、筛选、排序 | 本地内容的完整检索、筛选和排序。 | 中高。依赖读索引与全文检索，G2 定三页默认搜索对象/范围、首版「个人/非个人/全部」与「本地/第三方/其他连接」的入口呈现、筛选排序清单。未开通的来源不形成可用服务。 |

### 已确认延后及既有红线

| 延后项 | 边界 |
| --- | --- |
| 个人云盘、局域网读取、跨设备文件传输 | 个人网盘/远程持有文件、SMB/Wi-Fi 等远端读取、应用内整文件传输均延后。也不做跨设备条目同步。应用外使用 iOS「文件」拷入、访问已经本地可读的授权文件属于首版。云占位的安全识别用于保护首版本地扫描，不等于接入云目录。 |
| Wi-Fi 音频输出 | 发起人明确延后 AirPlay 等。首版覆盖系统有线、已知 USB DAC、扬声器与蓝牙。额外 DAC 专项适配、独占输出及其他协议暂无首版承诺。 |
| 第三方和跨来源 | Qobuz、Apple Music 等第三方合规服务、跨来源同曲/版本识别与收藏关联延后。远程默认按需读取、可动态清理缓存，永久下载只由用户发起并在允许范围内执行。来源与缓存候选见[技术调研](../research/TECH_STACK_COMPARISON.md#4-远程来源与缓存--首版后)。 |
| 其他平台与系统能力 | Android、Windows、跨设备灰显与自动同步后置。macOS 当前不在项目范围。 |

全局遵守纯客户端、无自建后端/Fidelune 账号、无独立临时播放队列、无主动推荐和本地聆听统计、无自定义音效和泛社交模块，以及不修改/删除用户原始音频等红线。最近 500 首播放历史仍保留。长期产品规则见 [PRODUCT_DESIGN.md](../../PRODUCT_DESIGN.md)。

### P1-T3 文件访问用例

1. **容器与导入。** 用可丢弃测试集核对「文件」App 可见容器、批量拷入/移出和增量索引，核对源文件及其标签未被播放器改写。分别验证 Offload、Delete、正常覆盖和续签，记录容器媒体、索引、组织数据、缓存及书签是否保留。涉及删除只用隔离副本。
2. **授权与可访问性。** 验证外部本地单文件/目录选择、深层遍历、退出重开及重启后恢复书签、失效/撤权、移动或重命名、暂不可用与重新关联。分别验证前台、锁屏时已打开和新打开的文件。记录各 provider 行为，不假定选择器返回的路径可长期直接读取。
3. **发现变化与回归。** 目录新增、移动、修改、删除前后比较前台监听与启动/切前台/进入视图增量快照。后台挂起后检查补扫，无法可靠监听时采用前台增量加手动刷新。扫描中断/重试不破坏已建立的索引，也不干扰播放。
4. **云占位防误读。** 条件允许时确认「文件」提供器中未物化条目怎么被发现、跳过或提示。首轮目标是避免本地扫描被整文件拉取或阻断，不需要登录并接入云盘 API，也不验证远程曲库能力。
